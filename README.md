# הלפרין — לימוד רוסית

אתר ללימוד רוסית בעברית. דף HTML אחד, בלי תלויות, עובד גם אופליין.

## מה יש בו

- **אלפבית** — 33 האותיות הקיריליות עם תעתיק בעברית, מילת דוגמה והשמעה
- **מילים** — 66 מילים וביטויים ב-6 נושאים, עם תעתיק והשמעה
- **כרטיסיות** — תרגול זיכרון עם כרטיס שמתהפך
- **הטיות** — 147 פעלים, 882 צורות בזמן הווה. מופיע פועל מוטה ובוחרים את הגוף;
  אחרי התשובה נפתחת טבלת ההטיה המלאה, וכל שורה ניתנת להשמעה
- **תרגול** — 10 שאלות אמריקאיות

ההשמעה מבוססת על מנוע הדיבור של הדפדפן (`ru-RU`). אם אין קול רוסי מותקן,
הדף אומר זאת במפורש — התעתיק בעברית מופיע תמיד.

כל הפעלים הם בצורה הלא-מושלמת (imperfective), כי לפעלים מושלמים אין זמן הווה ברוסית.
